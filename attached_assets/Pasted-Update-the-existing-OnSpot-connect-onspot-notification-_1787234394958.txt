Update the existing OnSpot / `connect-onspot` notification bell UI.

## GOAL

Change the unread notification indicator on the **Notification Bell only**.

Current behavior:

```text
Bell icon + red badge with number
Example:
4
```

Desired behavior:

```text
Bell icon + small red dot
```

No number.

The red dot should simply indicate:

> There is at least one unread notification.

This change must apply to BOTH:

* Client
* Talent

---

# VERY IMPORTANT SCOPE

This change is ONLY for the Notification Bell.

Do NOT change numeric unread badges anywhere else.

Keep numeric counts on:

* Client sidebar → Messages
* Client Profile dropdown → Messages
* Talent Profile dropdown → Messages
* Talent My Applications → Messages button
* `Message` buttons in Job Submissions
* `Reach the Client`
* conversation/thread unread counts
* any other message-specific unread counters

Those should remain numeric.

Only the Bell becomes a dot.

---

# EXPECTED BEHAVIOR

## Zero unread notifications

Show:

```text
Bell icon
```

No red dot.

## One or more unread notifications

Show:

```text
Bell icon + red dot
```

Whether there is:

* 1
* 2
* 4
* 25

the Bell should look exactly the same.

Do NOT display the number.

# IMPLEMENTATION

If the current code does something like:

```tsx
{unreadCount > 0 && (
  <span className="...">
    {unreadCount}
  </span>
)}
```

change it conceptually to:

```tsx
{unreadCount > 0 && (
  <span
    className="absolute rounded-full bg-red-500"
    aria-label="Unread notifications"
  />
)}
```

Adapt to the existing component/classes.

Do not hardcode the exact example if the design system already has a shared notification indicator style.

---

# DOT SIZE

Keep it small.

Suggested approximate dimensions:

```text
6px–8px
```

or:

```text
w-2 h-2
```

Use whatever looks visually balanced with the existing Bell.

Do not make it large enough to look like a button.

---

# DOT POSITION

Place the red dot near the upper-right corner of the Bell icon.

Example:

```text
      ●
    🔔
```

It should not:

* cover most of the Bell
* shift the Bell position
* change TopNavigation height
* affect neighboring buttons

Use absolute positioning inside a relative Bell container.

---

# ACCESSIBILITY

Because the number is no longer visible, preserve an accessible indication.

For example:

```tsx
aria-label={
  unreadCount > 0
    ? `${unreadCount} unread notifications`
    : "Notifications"
}
```

The visual dot should not be the only information available to screen readers.

The tooltip/dropdown may still show actual notification details.
