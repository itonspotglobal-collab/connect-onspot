- Virtual Assistant

The matching engine is still too loose and is incorrectly showing jobs outside the candidate’s real niche.

Required fix:
Add a strict domain/job-family gate before scoring jobs.

Important rule:
The Target Job Position and finalized niche/category must act as a hard filter before broader scoring.

Examples:
- Developer → should only match software development / engineering / web development / application development / closely related technical build roles

  - Virtual Assistant
