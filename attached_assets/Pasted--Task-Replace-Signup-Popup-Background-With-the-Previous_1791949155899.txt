The signup form should appear as a modal overlay on top of the actual page the user was browsing.

1. User visits the Find Work page.
2. User clicks Sign Up.
3. The existing Talent signup form opens as a popup.
4. The Find Work page remains visible behind the popup.
5. Apply a subtle blur and slightly darkened overlay to the Find Work page.
6. The signup form remains sharp, clear, and fully interactive.
7. Clicking X closes the popup and reveals the Find Work page at the same scroll position.

**Scenario B — Hire Talent**
1. User visits the Hire Talent page.
2. User clicks Sign Up.
3. The existing Client signup form opens as a popup.
4. The Hire Talent page remains visible behind the popup with a subtle blur.
