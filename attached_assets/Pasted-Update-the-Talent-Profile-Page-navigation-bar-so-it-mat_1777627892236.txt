Update the Talent Profile Page navigation bar so it matches the main OnSpot branding design.

Current issue:

* The Talent Profile navigation bar works and looks clean.
* However, it does not fully match the current OnSpot brand/navbar style.
* It should look more consistent with the main website navbar shown on the Find Work / landing page.

Branding direction:
Use the main OnSpot navbar as the visual reference:

* purple gradient background
* white OnSpot logo
* clean centered navigation links
* modern rounded CTA button
* premium/light glow effect
* consistent spacing and typography
* polished SaaS-style layout

Do not copy LinkedIn styling. The profile page navbar should look like it belongs to OnSpot.

Required updates:

1. Change the Talent Profile navbar background from white to the OnSpot purple gradient style.
2. Use the white OnSpot logo/wordmark instead of the small plain text logo.
3. Match the main website navbar spacing and layout.
4. Use similar navigation items as the branded navbar:

   * Hire Talent
   * Find Work
   * Why OnSpot
   * Solutions
   * Amazing
5. Add a right-side CTA button similar to the main website:

   * If not logged in: `Access Portal` or `Sign in`
   * If logged in as talent: show avatar/profile menu or `My Profile`
6. Use icons only if they match the brand style. Avoid mismatched thin/gray icons if they make the navbar feel different.
7. Keep the navbar responsive.
8. On mobile, collapse links into a menu button.

Expected result:
