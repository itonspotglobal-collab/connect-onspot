Update the existing /client-dashboard page to match the attached dashboard reference as closely as possible.

Do not redesign or replace the existing left navigation sidebar. Focus only on the dashboard content area to the right of the sidebar.

Overall Structure

Use a responsive three-column dashboard layout:

Main left area: approximately 66–70% width
Right sidebar area: approximately 30–34% width
The left area should contain:
Home Dashboard header
VA overview
Attendance dashboard
Financial overview
Documents
The right area should contain:
Communication
Requests
Notifications
AI Assistant

The page should be dense but readable, similar to a professional HRMS or workforce-management dashboard.

1. Page Header

At the top of the main content area, show:

Title: Home Dashboard

Subtitle:
Overview of your VA, attendance, financials and important updates

Keep the header compact with minimal vertical spacing.

Visual Design

Match the reference with:

White cards
Very light gray page background
Thin gray borders
Small border radius, approximately 8–10px
Minimal shadows
Compact card padding
Blue as the primary accent
Green for success and active statuses
Orange for warnings
Red for missed or overdue items
Small professional icons
Tight table spacing
Clear information hierarchy

Avoid:

Oversized cards
Excessive whitespace
Heavy gradients
Large rounded corners
Strong shadows
Decorative charts that are not shown in the reference
Responsive Behavior
Desktop
Two-column main content section
Right-side utility column remains visible
VA Overview spans the full width of the left content area
Tablet
Attendance and Financial Overview may stack
Right utility panels move below the main content
Mobile
All cards stack vertically
Tables become horizontally scrollable
Contact and request rows remain touch-friendly
The AI Assistant remains accessible near the bottom of the page

Acceptance Criteria

The implementation is complete when:

The dashboard closely matches the attached reference layout.
The existing side navigation remains unchanged.
All requested sections are visible.
Attendance and invoice tables are implemented.
Documents are separated into VA and Company groups.
Communication, Requests, Notifications, and Vanessa appear in the right column.
The layout is responsive.
Existing APIs and reusable components are used where available.
Buttons have working navigation, modal behavior, or clearly defined placeholders.
The page has loading, empty, and error states.
No unrelated pages or global styles are broken.
