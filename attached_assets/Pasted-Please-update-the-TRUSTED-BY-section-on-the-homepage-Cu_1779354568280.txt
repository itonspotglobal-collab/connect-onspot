--------------------------------------------------
CAROUSEL BEHAVIOR
--------------------------------------------------

Implement a horizontal carousel for the client logos.

Requirements:
1. Automatic movement
- Carousel should autoplay.
- Move smoothly from logo to logo.
- Suggested interval: every 3 to 4 seconds.
- Pause autoplay when the user hovers over the carousel.
- Pause autoplay when the user interacts manually.

2. Manual controls
Add manual carousel controls:
- Previous button
- Next button

Controls should:
- Be visible but subtle.
- Match the site’s existing button/icon style.
- Be accessible with aria-labels:
  - aria-label="Previous client logos"
  - aria-label="Next client logos"

Optional:
- Add small pagination dots below the carousel if easy, but not required.

3. Responsive behavior
Desktop:
- Show multiple logos at once, ideally 4 to 5 visible depending on screen width.

Laptop:
- Show 3 to 4 logos.

Tablet:
- Show 2 to 3 logos.

Mobile:
- Show 1 to 2 logos.

The carousel must not cause horizontal page scrolling.

--------------------------------------------------
AUTOPLAY LOGIC
--------------------------------------------------

Use React state:

- currentIndex
- visibleCount based on screen size or calculated using CSS/card width
- nextSlide()
- prevSlide()

Autoplay:
- useEffect with setInterval
- Clear interval on unmount
- Pause when hovering:
  - onMouseEnter setIsPaused(true)
  - onMouseLeave setIsPaused(false)

Make sure carousel loops correctly:
- When reaching the end, return to the first slide.
- When clicking previous on the first slide, go to the last available slide.
