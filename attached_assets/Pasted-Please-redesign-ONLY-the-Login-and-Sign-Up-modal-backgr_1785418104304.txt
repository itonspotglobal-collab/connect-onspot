==================================================
REMOVE THE GRID / PATTERN
==================================================

The modal currently has visible vertical and horizontal grid lines.

Remove ALL of them.

Specifically remove any:

- background-image
- linear-gradient used for grid lines
- repeating-linear-gradient
- radial-grid pattern
- CSS pseudo-elements (::before / ::after) used to create the grid
- overlay elements used only for the grid effect

The modal background should be COMPLETELY PLAIN.

==================================================
BACKGROUND COLOR
==================================================

Replace the current dark purple background with a smooth light frosted color.

Target appearance:

- Soft bluish white
- Very light gray-blue
- Slight lavender tint
- Premium glass look

Use something close to:

background: rgba(236, 240, 250, 0.92);

or

background: rgba(242, 245, 252, 0.90);

or

#EEF2FA with 90–95% opacity.

No gradients.
No patterns.
No texture.

The background should be one uniform color.
