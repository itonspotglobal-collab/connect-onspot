# PART 1 — IMPROVE STEP 3 REQUIREMENTS FORMATTING

The current Requirements page is functional, but the individual sections blend together too much.

Improve the visual hierarchy so clients can scan the page more easily.

Do not radically redesign the page. Keep it consistent with the existing OnSpot job-posting design.

## Increase section heading size and weight

Increase the font size and make these labels clearly bold:

* Minimum educational attainment
* Required Skills
* Availability
* Compensation

Currently some of these use small uppercase eyebrow-style text. That is too subtle.

Change them into clear section/question headings.

Suggested visual treatment:

```text
1. Minimum educational attainment
2. Required Skills
3. Availability
4. Compensation
```

Use approximately:

* `text-base` or `text-lg`
* `font-bold`
* strong foreground text

Do not make them oversized like the main `Requirements` page heading.

The hierarchy should be:

```text
Requirements                     <- main page heading

1. Minimum educational attainment <- section heading
[field]

2. Required Skills                <- section heading
[skill controls]

3. Availability                   <- section heading
[availability cards]

4. Compensation                   <- section heading
[compensation controls]
```

# Invite to Apply behavior

When the Client clicks:

`Invite to Apply`

the workflow should allow the Client to select which active/open job they want to invite the talent to.

Preferred flow:

```text
Invite to Apply
      ↓
Choose Job Opening
      ↓
Confirm Invitation
      ↓
Talent receives invitation
```

If only one eligible job exists, you may simplify the selection UX, but do not make assumptions that every Client has only one job.

If the Client has no available jobs, show a helpful state such as:

`You need an active job posting before inviting talent to apply.`

and offer:

`Post a Job`

which routes to the existing Client Create Job form.
