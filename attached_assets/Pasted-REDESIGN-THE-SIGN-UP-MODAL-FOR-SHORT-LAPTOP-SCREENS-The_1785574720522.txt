REDESIGN THE SIGN-UP MODAL FOR SHORT LAPTOP SCREENS

The current Sign Up modal still looks poor on smaller laptop screens.

The latest implementation added `overflow-y-auto`, but this only makes the
modal scroll internally. The actual layout is still too tall and vertically
compressed.

Do not keep solving this by adding more scrolling.

Instead, redesign the desktop/laptop modal so the complete signup form fits
naturally within short screens such as 1280×720 and 1366×768.

TARGET

Review the Sign Up modal inside:

`client/src/components/TopNavigation.tsx`

The browser inspector currently shows a large scrollable body similar to:

`flex flex-col ... overflow-y-auto flex-1 min-h-0`

Restructure this component.

DESKTOP / LAPTOP DESIGN

For screens wider than approximately 768px, use a compact two-column signup
layout.

Target structure:

The entire modal should fit within a 720px-high viewport without requiring
scrolling under normal conditions.

MODAL DIMENSIONS

Desktop/laptop:

- width: approximately 600–680px
- max-width: around 680px
- height: auto
- max-height: `calc(100dvh - 32px)`
- centered horizontally
- centered vertically only if enough space exists
- on short screens, use approximately 12–16px top/bottom viewport margin

Do not make the modal 100% height on laptop screens.

Do not make the normal desktop form internally scrollable if all content can
fit naturally.

Fields:

- Last Name

PASSWORD / CONFIRM PASSWORD

EMAIL

FORM SPACING

Use compact but readable spacing:

- modal padding: 20–24px
- field vertical gap: 10–12px
- label-to-input gap: 4px
- section gap: 12–16px

Avoid large values such as:

- `space-y-6`
- `space-y-8`
- excessive `py-*`
- excessive bottom margins

INPUT HEIGHT

Use approximately:

`h-10`

or around 40px.

Keep inputs accessible and readable.

PASSWORD COPY

Remove this sentence:

“Shown in plain text so you can verify what you're saving.”

It adds unnecessary height and is confusing.

Instead, use a concise helper only when needed:

`8+ chars with uppercase, lowercase, number & symbol`

Prefer showing this only below the Password field or as validation feedback.

60–72px.

Keep:

- icon
- title
- subtitle

Remove excess vertical padding.

If some explanation is required, reduce it to:

`Talent profiles can be completed after signup.`

or omit it entirely.

CTA

The Create Account button should be part of the natural modal layout on desktop
and visible without scrolling.

Keep it:

- full width
- approximately 42–44px height
- directly below role selection
- modest top margin

Do NOT hide it at the bottom of a scrolling container.

SIGN IN LINK

Place:

`Already have an account? Sign In`

directly below the Create Account button.

Keep this visible on 1280×720 and 1366×768.

CLOSE BUTTON

The close X must remain inside the modal header.

Do not allow it to overlap First Name / Last Name.

The screenshot currently shows content appearing too close to the top edge.

Add a dedicated header section so fields never appear behind or beside the
close button.

SHORT-LAPTOP MODE

Add viewport-height-specific compact styling.

- modal padding: 16px 20px
- reduce header margin
- use 40px inputs

- hide nonessential helper text
- do NOT shrink fonts excessively

The modal should still look intentionally designed, not squeezed.

DO NOT USE INTERNAL SCROLLING ON NORMAL LAPTOP WIDTHS UNLESS NECESSARY

At:

- 1280×720
- 1366×768
- 1440×800

the complete signup form should fit naturally.

Only introduce an internal scrollbar when:

- validation errors make the form taller;
- browser height is unusually small;
- accessibility/font scaling requires additional room.
