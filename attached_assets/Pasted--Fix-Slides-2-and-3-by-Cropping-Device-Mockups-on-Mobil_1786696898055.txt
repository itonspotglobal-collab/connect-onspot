# Slide 2 — Tablet / Team Dashboard

The current tablet is too tall and causes the entire carousel control row to disappear.

## New mobile behavior

Create a dedicated wrapper around the tablet visual.

Concept:

```tsx
<div className="hero-mobile-device-window">
  <LaptopMockup />
</div>
```

On mobile only:

```css
.hero-mobile-device-window {
  position: relative;
  width: 100%;
  height: 330px;
  overflow: hidden;

  display: flex;
  justify-content: center;
  align-items: flex-start;
}
```

The exact height can be adjusted between approximately:

```css
300px - 360px
```

depending on screen height.

The tablet itself should remain centered inside this crop window.

Example:

```css
.hero-tablet-mobile {
  width: min(76vw, 340px);
  margin-inline: auto;
  transform-origin: top center;
}
```

If necessary:

```css
.hero-tablet-mobile {
  transform: scale(0.9);
}
```

but only on mobile.

## Important

Do NOT scale the tablet so much that the dashboard becomes tiny.

It is preferable to show:


# Hero Mobile Flex Structure

On mobile, use something similar to:

```tsx
<section className="...">
  <div className="hero-mobile-layout">

    <div className="hero-mobile-content">
      {/* slide text */}
      {/* CTA */}
      {/* cropped device area */}
    </div>

    <div className="hero-carousel-controls">
      ...
    </div>

  </div>
</section>
```

Mobile CSS concept:

```css
.hero-mobile-layout {
  height: 100%;
  display: flex;
  flex-direction: column;
}

.hero-mobile-content {
  flex: 1;
  min-height: 0;
  overflow: hidden;
}

.hero-carousel-controls {
  flex-shrink: 0;
}
```

This guarantees that the device gets cropped before the carousel controls disappear.

# Responsive Crop Height

Because mobile phones have different heights, you can use CSS such as:

```css
@media (max-width: 767px) {
  .hero-mobile-device-window {
    height: clamp(250px, 36vh, 350px);
  }
}
```

For shorter screens:

```css
@media (max-width: 767px) and (max-height: 700px) {
  .hero-mobile-device-window {
    height: 240px;
  }
}
```

For taller phones:

```css
@media (max-width: 767px) and (min-height: 800px) {
  .hero-mobile-device-window {
    height: 320px;
  }
}
```

This is much safer than using one giant fixed device size.
