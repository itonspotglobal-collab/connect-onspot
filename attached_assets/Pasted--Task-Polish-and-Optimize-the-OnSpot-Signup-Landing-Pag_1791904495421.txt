## Task: Polish and Optimize the OnSpot Signup Landing Page

Improve the existing OnSpot Signup Landing Page to provide a more modern, professional, user-friendly experience while maintaining the current OnSpot branding and functionality.

**Primary Goal:** Polish and optimize fonts, messaging, and overall user experience.

### 1. Improve Typography and Visual Hierarchy

- Use consistent font sizes, weights, and spacing throughout the signup experience.
- Make headings clear and visually prominent without being oversized.
- Improve the readability of subtitles, form labels, placeholders, and helper text.
- Maintain consistent typography between Client and Talent signup pages.
- Ensure adequate text contrast, especially on dark backgrounds.
- Improve line heights and spacing for a cleaner, more polished appearance.

### 2. Optimize Signup Messaging

Review and refine the wording throughout the signup experience to make it clear, welcoming, and action-oriented.

Suggested messaging:

**Signup Portal Selection**

Heading: "Get started with OnSpot"

Subtitle: "Choose how you'd like to join OnSpot."

**Client Option**

Title: "I'm Hiring"

Description: "Find and manage vetted global talent for your business."

Button: "Get Started →"

**Talent Option**

Title: "I'm Looking for Work"

Description: "Discover global opportunities and grow your career."

Button: "Get Started →"

**Talent Signup Form**

Heading: "Find Work"

Subtitle: "Create your profile and connect with global opportunities."

Primary Button: "Create Talent Profile →"

**Client Signup Form**

Heading: "Hire Talent"

Subtitle: "Create your account and start building your remote team."

Primary Button: "Create Client Account →"

Keep the messaging concise, professional, and consistent with OnSpot's brand positioning.

### 3. Improve Form Layout and User Experience

- Maintain the existing signup form structure.
- Improve spacing between form fields, labels, and buttons.
- Ensure input fields have consistent heights, border radius, and padding.
- Make required fields and validation messages easy to understand.
- Improve the password requirements section so it is readable and does not overwhelm the form.
- Use clear inline validation and helpful error messages.
- Ensure the Terms of Service and Privacy Policy links are clearly visible and clickable.
- Make the primary signup button visually prominent.
- Include appropriate loading and disabled states to prevent duplicate submissions.
- Ensure keyboard navigation and focus indicators work correctly.

### 4. Improve Back Navigation

Use the previously requested navigation improvements.

- Add a visible **"← Back to Portal"** button on Client and Talent signup forms.
- Position it at the top-left of the form card.
- Use a subtle outlined button consistent with the OnSpot design.
- Return users to the Client/Talent portal selection screen.
- Preserve the original page the user visited before entering signup.
- From the portal selection screen, allow users to return to that original page instead of always going to Home.

### 5. Maintain OnSpot Branding

Preserve the existing visual identity:

- Dark navy signup form background.
- Purple and blue gradient primary buttons.
- OnSpot logo and branding.
- Rounded form containers.
- Clean, modern card styling.
- Consistent iconography.

Avoid a complete redesign. Focus on improving the current experience.

### 6. Optimize Mobile Responsiveness

- Ensure the signup pages work well on desktop, tablet, and mobile.
- Prevent text overflow and overlapping elements.
- Use responsive form widths and padding.
- Stack multi-column fields vertically on smaller screens.
- Ensure buttons and input fields are easy to tap.
- Avoid unnecessary horizontal scrolling.

### 7. Preserve Existing Functionality

Do not break or modify:

- Existing signup and authentication logic.
- Client and Talent account creation.
- LinkedIn signup integration.
- Form validation and password requirements.
- Existing API calls and database integration.
- Terms of Service and Privacy Policy links.
- Successful registration redirects.

### 8. Verify the Improvements

Test both Client and Talent signup flows.

Confirm that:
- All text is readable and visually consistent.
- Messaging is clear and grammatically correct.
- Forms are easy to complete.
- Back navigation works correctly.
- Responsive layouts display properly.
- All existing signup functionality remains operational.

### Expected Result

A polished, professional, and user-friendly OnSpot signup experience with improved typography, clearer messaging, consistent styling, intuitive navigation, and responsive layouts.

**Important:** Prioritize UI/UX improvements and content refinement. Do not rebuild the signup system or make unnecessary changes to backend functionality.
