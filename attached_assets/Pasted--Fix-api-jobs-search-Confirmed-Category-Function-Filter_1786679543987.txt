# Fix `/api/jobs/search` — Confirmed Category/Function Filter Bug

We have now confirmed that the `/find-work/jobs` category filter is still broken.

## Reproduction

A test job was created/edited with:

```text
Job title: Test
Function: Engineering
Status: Open
```

The Admin Job Form shows:

```text
Function = Engineering
```

The public Find Work filter contains:

```text
Engineering
```

When clicking the Engineering filter, the page still shows:

```text
0 roles found
```

This proves this is no longer just a naming mismatch between Function and Category.

The backend search/filter query needs to be investigated.

# Step 4 — Category Must Match `jobFunction` OR `category`

The API must treat the Find Work `category` parameter as the selected job function taxonomy.

For:

```text
category=Engineering
```

match:

```text
job.jobFunction = Engineering
```

OR:

```text
job.category = Engineering
```

Conceptually:

```ts
or(
  ilike(jobs.jobFunction, "Engineering"),
  ilike(jobs.category, "Engineering")
)
```

Use the actual Drizzle column names.

Do not search only:

```ts
jobs.category
```

and do not search only:

```ts
jobs.jobFunction
```

Support both because of legacy data.

# Important Diagnostic

Run these two searches directly:

```text
GET /api/jobs/search?status=open&page=1&pageSize=25
```

and:

```text
GET /api/jobs/search?status=open&page=1&pageSize=25&category=Engineering
```

Compare the results.

### Scenario A

If the Test Engineering job appears in the first request but disappears in the second:

**Category filtering is definitely broken.**

Fix the category condition.

### Scenario B

If the Test Engineering job does NOT appear even in the unfiltered request:

The problem is NOT primarily the Category filter.

Investigate:

* approval status
* publication status
* status normalization
* account ownership
* public visibility query

This diagnostic must be performed before finalizing the fix.
