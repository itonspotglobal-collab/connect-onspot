3. USE CENTER-FOCUSED DISPLAY LOGIC
--------------------------------------------------

Instead of sliding a track that can get confused, calculate the visible logos around the active center index.

Use the active index as the CENTER item.

Example:
const getVisibleLogos = () => {
  const visibleCount = getVisibleCount(); // 5 desktop, 3 tablet, 1 mobile
  const half = Math.floor(visibleCount / 2);

  return Array.from({ length: visibleCount }, (_, position) => {
    const offset = position - half;
    const logoIndex = (currentIndex + offset + logos.length) % logos.length;

    return {
      ...logos[logoIndex],
      logoIndex,
      offset,
      position,
      isActive: offset === 0,
    };
  });
};

This ensures:
- The active logo is always centered.
- Next moves the center to the next logo.
- Previous moves the center to the previous logo.
- The order stays correct and circular.

6. RESPONSIVE VISIBLE COUNT
--------------------------------------------------

Use responsive visible counts:
- Desktop/lg and up: 5 logos visible
- Tablet/md: 3 logos visible
- Mobile: 1 logo visible, or 3 if it still fits

Suggested:
const [visibleCount, setVisibleCount] = useState(5);

useEffect(() => {
  const updateVisibleCount = () => {
    if (window.innerWidth < 640) setVisibleCount(1);
    else if (window.innerWidth < 1024) setVisibleCount(3);
    else setVisibleCount(5);
  };

  updateVisibleCount();
  window.addEventListener("resize", updateVisibleCount);
  return () => window.removeEventListener("resize", updateVisibleCount);
}, []);

Make sure visibleCount is always odd so there is a real center item.
