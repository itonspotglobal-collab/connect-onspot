## Existing Correct Rule — KEEP THIS EXACTLY

Talent names must display as:

`First Name + Last Name Initial`

Example:

`Frenzy Val Eloise Legaspi`

must display as:

`Frenzy L.`

NOT:

`Frenzy Val Eloise L.`

NOT:

`Frenzy Val Eloise Legaspi`

NOT:

`F****`

The first name means the person's actual FIRST name only.

The last name should be reduced to its first initial followed by a period.

More examples:

```text
Robert Smith
→ Robert S.

Mary Anne Cruz
→ Mary C.

Jean-Paul O'Connor
→ Jean-Paul O.

Frenzy Val Eloise Legaspi
→ Frenzy L.
```

For a multi-part full name, use:

* first token/name = first name
* last token/name = last name
* ignore middle names for display purposes

So:

```text
Frenzy Val Eloise Legaspi
```

becomes:

```text
Frenzy L.
```
