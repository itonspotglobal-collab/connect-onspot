Build a React + TypeScript dashboard page for "OnSpot" — a talent outsourcing platform. Use Tailwind CSS for styling, shadcn/ui for components (Card, Badge, Button, Progress, Avatar, Select, Table), and Recharts for all charts. The design uses a clean light/dark-mode-compatible layout with `space-y-6` vertical rhythm.

---

## TECH STACK
- React + TypeScript
- Tailwind CSS (utility-first, dark mode via `dark:` classes)
- shadcn/ui components
- Recharts (BarChart, LineChart, ResponsiveContainer, XAxis, YAxis, CartesianGrid, Tooltip, Legend, LabelList, Bar, Line, Area)
- lucide-react icons

All mock data should be inline arrays. No external API calls. Components should be self-contained in a single Dashboard.tsx file.
