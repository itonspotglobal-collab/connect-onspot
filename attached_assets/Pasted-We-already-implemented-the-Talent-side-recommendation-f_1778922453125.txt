Now we need to implement the Client side recommendation feature.

Goal:
When a logged-in client account visits the Find Talent page, Client Dashboard, or any existing talent browsing page, the site should show “Suggested Talents” or “Recommended Talents” related to the client’s company, interests, and job postings.

This is the reverse of the existing talent-side feature.

Existing working behavior:
Talent Profile → Recommended Job Openings

New behavior needed:
Client Profile + Company Info + Job Postings → Recommended Talents

Important:
Use the same pattern, helper structure, scoring logic, and UI approach already implemented for the talent-side recommendation feature.
Do not rebuild from scratch.
Reuse existing components, APIs, cards, matching logic, and recommendation helpers as much as possible.

1. The existing working talent-side recommendation implementation.

9. Existing API routes in server/routes.ts.

Main requirement:
For logged-in client users, show a “Suggested Talents” or “Recommended Talents” section.

This section should recommend talents based on:
- Client company profile
- Company industry
- Company description
- Business type
- Client interests if available
- Existing active job postings
- Job post titles
- Required skills from job postings
- Job post categories
- Job post descriptions
- Job post qualifications
- Job post responsibilities

Example:
If a client has job postings for:
- Software Developer
- IT Administrator
- Technical Support

Then Suggested Talents should prioritize talents with:
- Software development skills
- React, Node.js, TypeScript, JavaScript, PHP, Laravel, etc.
- IT administration experience
- Technical support background
- System administration skills

Do not hardcode these terms. They are only examples.

Suggested scoring:

- Talent skills match job post required skills: +6
- Talent experience title matches job post title/category: +5
- Talent bio/about matches keyword: +2
- Talent category/industry matches company/job category: +4
- Talent portfolio/project tags match keyword: +3
- Exact keyword match bonus: +3

Only show talents with score greater than 0.

Limit recommended talents to 6 or 8 initially.
