Add Responsive Search Bar to Insights Page

I want to add a search bar for filtering blog posts in my Insights page. The search should be clean, responsive, and integrated with existing category filters.

✅ Requirements:

Place search bar below the description and above category filters

Filter articles by:

title

excerpt

author

Works together with category filter

Fully responsive (no overflow or layout breaking)

Debounced input (optional but preferred)

Do NOT affect existing layout or components

🔧 Step 1: Add State for Search

Inside Insights():

const [searchQuery, setSearchQuery] = useState("");
🔧 Step 2: Add Search UI (IMPORTANT: Placement)

👉 Place this RIGHT ABOVE the category filters block:

{/* Search Bar */}
<div className="max-w-xl mx-auto mb-6">
  <div className="relative">
    <input
      type="text"
      placeholder="Search insights, topics, or authors..."
      value={searchQuery}
      onChange={(e) => setSearchQuery(e.target.value)}
      className="w-full pl-10 pr-4 py-3 rounded-full border border-border bg-background text-sm focus:outline-none focus:ring-2 focus:ring-primary"
    />
    <svg
      className="absolute left-3 top-1/2 -translate-y-1/2 w-4 h-4 text-muted-foreground"
      fill="none"
      stroke="currentColor"
      strokeWidth="2"
      viewBox="0 0 24 24"
    >
      <path strokeLinecap="round" strokeLinejoin="round" d="M21 21l-4.35-4.35M16 10a6 6 0 11-12 0 6 6 0 0112 0z" />
    </svg>
  </div>
</div>
🔧 Step 3: Update Filtering Logic

Replace your filteredArticles with:

const filteredArticles =
  selectedCategory === "All Articles"
    ? allArticles
    : allArticles.filter((a) => a.category === selectedCategory);

const finalArticles = filteredArticles.filter((a) =>
  [a.title, a.excerpt, a.author]
    .join(" ")
    .toLowerCase()
    .includes(searchQuery.toLowerCase())
);

Replace:
