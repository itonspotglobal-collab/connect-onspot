We have an URGENT production authentication incident.

A large number of users are currently attempting to register/login. Desktop/laptop appears to work in testing, but many mobile users cannot complete signup/login.

Observed user behavior:
- User fills out signup.
- Submission fails or appears to loop.
- User remains on the signup page.
- Users retry multiple times.
- Some eventually hit signup rate limiting.
- Desktop/laptop appears to work more reliably than mobile.

We also observed live logs showing some signup attempts being rejected because the password is missing a required special character.

The current signup UI apparently only clearly communicates the 8-character minimum, so the frontend requirements may not match backend password validation.
