# 3. Update Engagement Type labels

The current Engagement Type dropdown displays:

* Standard
* Lite

Change the visible options to:

* `Standard (8 Hours)`
* `Lite (4 Hours)`

## Critical database requirement

These are **display labels only**.

The underlying submitted values MUST remain:

* `Standard`
* `Lite`

For example:

```tsx
<SelectItem value="Standard">
  Standard (8 Hours)
</SelectItem>

<SelectItem value="Lite">
  Lite (4 Hours)
</SelectItem>
```

Do NOT send these strings to PostgreSQL:

```text
Standard (8 Hours)
Lite (4 Hours)
```

The database/API canonical values must remain exactly:

```text
Standard
Lite
```

This is important because the `jobs.engagement_type` database constraint is intended to accept the canonical `Standard` / `Lite` vocabulary.

Apply the same display formatting everywhere the engagement type appears in this workflow, including:

* create form
* edit form
* review step
* job preview within the form

The UI may display:

`Standard (8 Hours)`

but the stored value must remain:

`Standard`

Likewise:

`Lite (4 Hours)` → stored as `Lite`.
