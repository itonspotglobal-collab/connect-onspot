Please fix the footer background issue.

Current issue:
The footer logo is now white, but the footer background is still light because there is a light overlay/background covering the actual footer background. We need to remove that light layer so the footer fully matches the navigation bar’s dark violet/blue color.

Goal:
The entire footer should have the exact same dark violet/blue background as the navigation bar, with no light overlay, no washed-out background, and readable white text.

IMPORTANT:
- Do not change the footer layout.
- Do not change footer spacing or columns.
- Only fix the background, overlay, logo, and text/icon colors.
- Inspect the actual footer component and CSS, not just the visible className.

--------------------------------------------------
1. Remove the light background overlay
--------------------------------------------------

Search the footer component and related CSS for any light overlays or pseudo-elements.

The footer currently appears to use something like:

<footer className="onspot-footer relative backdrop-blur-sm overflow-hidden">

Check for styles like:

.onspot-footer::before
.onspot-footer::after

or Tailwind classes like:

before:absolute
before:inset-0
before:bg-white
before:bg-slate-50
before:bg-gradient-to-b
before:from-white
before:via-white
before:to-transparent
after:absolute
after:inset-0
after:bg-white
after:bg-slate-50
bg-white
bg-slate-50
bg-gray-50
bg-[#f...]
backdrop-blur-sm

Remove or disable those light overlays.

If the footer has decorative blurred background divs inside it, make sure they are not covering the dark background with a pale color.

Example:
Remove this kind of layer:

<div className="absolute inset-0 bg-white/70 ..." />

or change it to:

<div className="absolute inset-0 bg-transparent pointer-events-none" />

If keeping decorative effects, make them subtle dark/purple, not white:

bg-purple-500/10
bg-blue-500/10

Find the exact navbar background class or CSS variable.
