--------------------------------------------------
GOAL
--------------------------------------------------

Create a 3D/coverflow-style logo carousel.

The center logo card should be:
- Largest
- Most visible

- In the front

--------------------------------------------------
LAYOUT STYLE
--------------------------------------------------

Instead of rendering cards in a normal flex row with equal spacing, render visible cards in a relative container and position them based on their offset from the active center.

Use this concept:

- offset 0 = active center card
- offset -1 = left near card
- offset 1 = right near card
- offset -2 = far left card
- offset 2 = far right card

The cards should overlap slightly or sit visually behind each other.

Suggested carousel stage:

className="
  relative mx-auto mt-16
  h-[260px]
  w-full max-w-6xl
  overflow-visible
"

Each card should be absolutely positioned:

className="
  absolute left-1/2 top-1/2
  flex items-center justify-center
  rounded-3xl border bg-white
  transition-all duration-700 ease-[cubic-bezier(0.22,1,0.36,1)]
"

Use transform styles based on offset.

--------------------------------------------------
POSITION / TRANSFORM LOGIC
--------------------------------------------------

Use a helper function to determine each visible card’s transform style.

Example:

const getCardStyle = (offset) => {
  const abs = Math.abs(offset);

  const styles = {
    0: {
      transform: "translate(-50%, -50%) translateX(0px) scale(1.18)",
      zIndex: 50,
      opacity: 1,
    },
    "-1": {
      transform: "translate(-50%, -50%) translateX(-260px) scale(0.88) rotateY(10deg)",
      zIndex: 30,
      opacity: 0.72,
    },
    "1": {
      transform: "translate(-50%, -50%) translateX(260px) scale(0.88) rotateY(-10deg)",
      zIndex: 30,
      opacity: 0.72,
    },
    "-2": {
      transform: "translate(-50%, -50%) translateX(-470px) scale(0.72) rotateY(16deg)",
      zIndex: 10,
      opacity: 0.35,
    },
    "2": {
      transform: "translate(-50%, -50%) translateX(470px) scale(0.72) rotateY(-16deg)",
      zIndex: 10,
      opacity: 0.35,
    },
  };

  return styles[offset];
};

Each card can use:

--------------------------------------------------
SMOOTH TRANSITION ANIMATION
--------------------------------------------------

When clicking next/previous or when autoplay runs:
- Cards should glide into their new positions.
- The new center card should smoothly scale up.
- The old center card should smoothly scale down and move to the side.
- No jumping, flickering, or instant reorder.

Use:
transition-all duration-700 ease-[cubic-bezier(0.22,1,0.36,1)]

Do not use transition-none.
Do not remount cards with changing keys that cause flickering.

Important:
Use a stable key based on the logo’s unique name or id, not the array position.

Example:
key={logo.name}

--------------------------------------------------
CAROUSEL ORDER / LOOPING
--------------------------------------------------

Keep the active index as the center logo.

Next:
const nextSlide = () => {
  setCurrentIndex((prev) => (prev + 1) % logos.length);
};

Previous:
const prevSlide = () => {
  setCurrentIndex((prev) => (prev - 1 + logos.length) % logos.length);
};

Visible logos:
const visibleOffsets = visibleCount === 5 ? [-2, -1, 0, 1, 2] : visibleCount === 3 ? [-1, 0, 1] : [0];

const visibleLogos = visibleOffsets.map((offset) => {
  const index = (currentIndex + offset + logos.length) % logos.length;
  return {
    ...logos[index],
    offset,
    index,
    isActive: offset === 0,
  };
});

This ensures:
- Center is always active.
- Next moves forward.
- Previous moves backward.
- No bouncing back to previous logo unless user clicks previous.
