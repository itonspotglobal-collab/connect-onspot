Fix the Find Talent page so it displays the talent’s real saved name instead of always showing the candidate fallback name like `Candidate DB1BE6`.

Current issue:

* The Talent Profile Page has the talent’s profile photo and profile information.
* The Find Talent page is showing the profile photo correctly.
* However, the talent name is still displayed as `Candidate DB1BE6`.
* It should display the real saved name of the talent when available.
* Candidate code should only be used as fallback when no real name exists.

Expected behavior:

1. If the talent has a saved full name, display the full name.
2. If there is no full name, display first name + last name.
3. If there is no first name or last name, display display name.
4. If no name exists at all, only then display `Candidate {candidateCode}`.
5. The same display name logic should be used in:

   * Find Talent card
   * Quick View modal
   * Full Talent Profile page
   * Any shortlist display

Recommended display priority:

```ts
const getTalentDisplayName = (talent) => {
  const name =
    talent.fullName ||
    [talent.firstName, talent.lastName].filter(Boolean).join(" ") ||
    talent.displayName ||
    talent.name ||
    talent.user?.fullName ||
    [talent.user?.firstName, talent.user?.lastName].filter(Boolean).join(" ") ||
    talent.profile?.fullName ||
    [talent.profile?.firstName, talent.profile?.lastName].filter(Boolean).join(" ");

  return name?.trim() || `Candidate ${talent.candidateCode}`;
};
```

Important:

* Do not hardcode `Candidate ${candidateCode}` as the primary name.
* Use it only as the final fallback.
