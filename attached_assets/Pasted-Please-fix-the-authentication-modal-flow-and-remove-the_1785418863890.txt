Please fix the authentication modal flow and remove the old intermediate authentication screen.

CURRENT ISSUES

1. The Sign In form styling is now too light and disconnected from the main site design.
2. Clicking the “Back” link from either:
   - Sign In
   - Create Account
   opens an old intermediate screen that says:
   “The first Superhuman BPO is awakening.”
3. We no longer want that old screen to appear anywhere in the authentication flow.

GOAL

Keep only two authentication views:

- Sign In
- Create Account

Users should move directly between these two views.

The old “Superhuman BPO” screen must no longer be shown.

====================================================
1. REMOVE THE OLD INTERMEDIATE SCREEN
====================================================

Locate the authentication view/state/component containing:

- “The first Superhuman BPO is awakening.”
- “AI first. Humans when it matters.”
- “Be the first to experience it”
- Sign In and Sign Up buttons

Remove it from the active authentication flow.

Do NOT necessarily delete the component file if it may still be needed later.
Instead:
- Stop rendering it.
- Remove it from the modal state transitions.
- Do not navigate back to it from Sign In or Create Account.

If the modal uses a state such as:

authView = "landing" | "signin" | "signup"

Remove `"landing"` from the current flow and use only:

authView = "signin" | "signup"

====================================================
2. CHANGE THE BACK BUTTON BEHAVIOR
====================================================

On the Sign In form:

- Replace the current “Back” behavior.
- It must NOT open the old Superhuman BPO screen.

Preferred behavior:
- Remove the “Back” link entirely from Sign In.

On the Create Account form:

- Replace the current “Back” behavior.
- It must NOT open the old screen.

Preferred behavior:
- Change “Back” to return directly to the Sign In form.

Example:

Sign In
- No Back link
- Bottom link: “Don’t have an account? Sign Up”

Create Account
- Back link → Sign In
- Bottom link: “Already have an account? Sign In”

The close “X” should continue closing the modal.

====================================================
3. DIRECT NAVBAR ACTIONS
====================================================

When the user clicks the navbar actions:

- “Log In” must open the Sign In form directly.
- “Sign Up” must open the Create Account form directly.

Do not open the removed intermediate screen first.

Suggested behavior:

openLoginModal():
  setAuthView("signin")
  setModalOpen(true)

openSignupModal():
  setAuthView("signup")
  setModalOpen(true)

====================================================
4. RESTYLE THE FORM PANEL
====================================================

The current panel is too pale and looks disconnected from the purple website.

Use a plain, light muted lavender-gray background that is darker than the current near-white version but still much lighter than the original dark purple.

Use a solid background close to:

background: #D8DAE8;

or:

background: #D2D4E3;

Do not use:
- Grid lines
- Patterns
- Transparent glass that lets the page show through heavily
- Dark purple gradients
- Near-white backgrounds

The panel should have one smooth, uniform color.

====================================================

- Main heading: #17182C
- Labels: #30344F
- Supporting text: #555B78
- Placeholder text: #858BA5

- Close and Back icons: #555B78

Do not keep white labels on the light panel.
