# Finalize Find Best Matches as One-Time Talent Onboarding

Task #103 is moving in the right direction, but the current behavior is still incorrect.

## Current problems

After successfully completing all steps in **Find Best Matches**:

1. the user reaches the personalized results page;
2. the Talent dropdown still shows:

```text
Profile completion: 0%
```

3. clicking `Talent Profile` sends the Talent back to:

```text
Find Best Matches
Step 1 of 5
```

4. the Find Best Matches journey resets to:

```text
20% complete
```

5. the Talent cannot access their Talent Profile even though they already completed onboarding.

This must be fixed permanently.

---

# Product behavior

Find Best Matches is primarily the Talent onboarding flow.

The intended lifecycle is:

```text
NEW TALENT
Create Talent Account
→ Find Best Matches onboarding
→ Complete onboarding once
→ Talent Profile becomes normal home/profile experience
```

After onboarding is completed:

```text
Talent Profile
Settings
My Applications
Find Work
```

must all remain accessible.

Find Best Matches should still be available later if the Talent intentionally wants to:

```text
Retake Assessment
Change Career Path
Update Job Preferences
Find New Matches
```

But it must NOT automatically restart or become a mandatory gate again.

---

# 1. Separate THREE concepts clearly

Do not mix these anymore.

## A. Onboarding completed

Persistent DB flag:

```ts
candidate.profileCompleted
```

Meaning:

```text
Has this Talent finished the initial Find Best Matches onboarding at least once?
```

Once true, it should normally remain true.

---

## B. Profile completion percentage

Calculated from Candidate/profile data:

```text
photo
name
headline
summary
email
phone
location
skills
experience
resume
preferences
etc.
```

This may be:

```text
58%
75%
100%
```

It can go up or down later.

It must NOT determine whether onboarding must restart.

---

## C. Find Best Matches journey progress

Temporary journey state:

```text
Step 1 of 5
Step 2 of 5
...
Step 5 of 5
```

and:

```text
20%
40%
60%
80%
100%
```

This only describes the current guided session.

Do not use it as profile completion.

# 3. Do NOT reset `profileCompleted` to false

Search the entire codebase for:

```text
profileCompleted: false
```

and any code that recalculates/replaces it.

Once initial onboarding is successfully completed:



* Summary was removed;

Those situations affect **profile completion**, not onboarding completion.

* [ ] `profileCompleted` survives logout/browser/device.

* [ ] Profile completion percentage is separate from onboarding completion.
* [ ] Dropdown no longer incorrectly shows 0% when Candidate data exists.

* [ ] Existing Resume is recognized in Find Best Matches.
* [ ] Hard refresh after onboarding does not reset to Step 1.
* [ ] New-device login does not restart onboarding.
