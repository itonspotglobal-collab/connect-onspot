# 6. INSPECT `getDefaultFormValues()`

The form currently uses:

```tsx
defaultValues: getDefaultFormValues(),
values: getDefaultFormValues(),
```

Investigate this carefully.

React Hook Form's `values` prop can continuously overwrite user edits when its input object changes/re-renders.

This can make the form appear editable but reset or interfere with submission.

Check whether `getDefaultFormValues()` creates a NEW object on every render.

If so, fix the synchronization pattern.

Preferred architecture:

```tsx
const form = useForm<ProfileFormData>({
  resolver: zodResolver(profileFormSchema),
  defaultValues: getDefaultFormValues(),
});
```

Then when profile data finishes loading:

```tsx
useEffect(() => {
  if (profile) {
    form.reset(getDefaultFormValues());
  }
}, [profile]);
```

Use appropriate stable dependencies.

Do NOT call `form.reset()` on every render.

Do NOT continuously overwrite dirty fields.
