# CURRENT PROBLEM

In Admin → Job Applications → Change Application Status:

the available choices currently include things like:

- Submitted
- Under Review
- Shortlisted
- Rejected

But `Hired` is not available.

We already tested an existing offer workflow:

Admin/Client sent a test offer
→ Talent accepted the offer

At this point, the application should become eligible to be moved to:

`Hired`

# DESIRED BUSINESS FLOW

The intended pipeline should be:

Application
→ Under Review
→ Shortlisted
→ Interviewing
→ Offer Extended
→ Offer Accepted
→ Hired

Do NOT allow arbitrary hiring before the offer has been accepted unless the existing business rules explicitly allow it.
