Enhance the Talent Profile Page by adding a dedicated profile navigation bar and additional profile features.

Current context:

* The Talent Profile Page is inspired by LinkedIn.
* It already displays:

  * cover/banner area
  * profile photo
  * talent display name
  * headline
  * location
  * work setup
  * profile strength
  * about section
  * skills section
  * preferences section
* The “Edit my profile” button should only be visible to the logged-in profile owner.
* Authentication should still only be active for the Talent Profile edit flow, not globally.

Main requirement:
Add a navigation bar to the Talent Profile Page, inspired by LinkedIn but visually different and consistent with OnSpot branding.

Feature 1: Talent Profile Navigation Bar

Add a top navigation bar for the Talent Profile Page.

Design requirements:

1. Use OnSpot branding, not LinkedIn branding.
2. Do not copy LinkedIn’s exact layout, icons, or colors.
3. The navbar should feel professional, clean, and consistent with the current purple/blue OnSpot design.
4. It should be sticky or fixed at the top if it improves navigation.
5. It should work well on desktop and mobile.

Suggested navbar contents:

* OnSpot logo or wordmark
* Search input or search icon
* Navigation links:

  * Home
  * Talent Pool
  * Find Work
  * Insights
  * Messages or Contact
* Profile menu/avatar on the right
* Optional sign-in/sign-out button depending on auth state

Suggested profile-specific secondary navigation:
Below the main navbar, add a section/tab navigation for the profile page:

* Overview
* About
* Skills
* Experience
* Education
* Resume
* Preferences
* Portfolio
* Contact

When clicked, each tab should scroll to the corresponding profile section.

Example:

```tsx id="3txgy8"
<nav className="profile-section-tabs">
  <button onClick={() => scrollToSection("overview")}>Overview</button>
  <button onClick={() => scrollToSection("about")}>About</button>
  <button onClick={() => scrollToSection("skills")}>Skills</button>
  <button onClick={() => scrollToSection("experience")}>Experience</button>
  <button onClick={() => scrollToSection("education")}>Education</button>
  <button onClick={() => scrollToSection("resume")}>Resume</button>
  <button onClick={() => scrollToSection("portfolio")}>Portfolio</button>
</nav>
```

Feature 3: Owner-only edit controls

Make sure edit controls are only visible to the profile owner.

Requirements:

1. If the logged-in user owns the profile:

   * show “Edit my profile”
   * show section edit buttons/icons
   * allow photo, name, headline, summary, skills, resume, and profile section updates

2. If the user is not logged in:

   * hide all edit buttons
   * show read-only profile

3. If the user is logged in but does not own the profile:

   * hide all edit buttons
   * show read-only profile

Use this rule:

```ts id="7jr0pl"
const isOwner =
  Boolean(authUser?.id) &&
  Boolean(talentProfile?.userId) &&
  authUser.id === talentProfile.userId;
```

Important:

```tsx id="qwkmit"
{isOwner && <EditProfileButton />}
```

Do not use:

```tsx id="o5848p"
{isAuthenticated && <EditProfileButton />}
```
