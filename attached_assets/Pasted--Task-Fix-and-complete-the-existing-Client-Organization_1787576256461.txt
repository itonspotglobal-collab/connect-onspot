Use the current repository implementation as the starting point.

The repository already contains:

* `organizations`

# 1. Fix the current invitation backend error

The Organization page currently produces an error similar to:

```text
400: {"error":"Only Client accounts can join an organization"}
```

when the owner tries to invite an email address.

This validation is occurring too early.

## Correct behavior

An organization owner must be allowed to send an invitation to **any valid email address**, even if that person has not created an OnSpot account yet.

Do NOT require a matching Client account when the invitation is initially created.

Change the flow to:

```text
Organization owner enters email
        ↓
Validate email format
        ↓
Ensure they are not already an active member
        ↓
Ensure there is not already a valid pending invitation
        ↓
Create organization invitation
        ↓
Generate secure invitation token
        ↓
Send invitation email
        ↓
Recipient opens invitation URL
        ↓
Recipient logs in or creates account
        ↓
Verify authenticated account email matches invited email
        ↓
Verify account role is client
        ↓
Accept invitation
        ↓
Create organization_members row
```

The **Client account requirement should happen on acceptance**, not while sending the invitation.

# 21. Permanent deletion after 3 days

```text

```
