Fix the Client Portal layout/routing inconsistency in the existing OnSpot / `connect-onspot` application.

## CURRENT BUG

The Client experience currently behaves inconsistently.

### Scenario 1 — Client opens Messages

When I visit:

`/messages`

the Client sidebar appears correctly underneath the blue/purple `TopNavigation`.

This is the desired layout.

### Scenario 2 — Client clicks the OnSpot logo

The blue `TopNavigation` currently has the logo hardcoded to:

```tsx
<Link href="/">
```

So clicking the OnSpot logo redirects the Client to `/`.

That route renders the old/default Home Dashboard WITHOUT the Client sidebar.

This causes the Client to bounce between two different Client layouts.

That must be fixed.

# PRIMARY FIX 1 — MAKE THE ONSPOT LOGO ROLE-AWARE

Audit:

`client/src/components/TopNavigation.tsx`

The logo currently does this:

```tsx
<Link href="/">
  <img ... />
</Link>
```

Do NOT leave this hardcoded for authenticated users.

Create a role-aware home route.

Conceptually:

```tsx
const getHomeRoute = () => {
  if (user?.role === "client") return "/dashboard";
  if (user?.role === "admin") return "/admin/dashboard";
  if (user?.role === "talent" || talentAuth) return "/my-applications";
  return "/";
};
```

Use the actual canonical routes from the existing application.

Then:

```tsx
<Link href={getHomeRoute()}>
```

The exact Talent route may differ based on existing product behavior, so verify before changing it.

# PRIMARY FIX 2 — MAKE THE SIDEBAR PART OF THE CLIENT SHELL

Do not solve this only by changing the logo.

The underlying issue is that the sidebar appears only on some routes.

Create or cleanly reuse a shared Client Portal shell.

Target architecture:

```tsx
<ClientPortalShell>
  <Page />
</ClientPortalShell>
```

Where:

```tsx
function ClientPortalShell({ children }) {
  return (
    <div className="min-h-screen">
      <TopNavigation />

      <div className="flex">
        <ClientSidebar />
        <main className="min-w-0 flex-1">
          {children}
        </main>
      </div>
    </div>
  );
}
```

Do NOT introduce another white header.

The blue `TopNavigation` remains the only top navigation.
