# Fix ONLY Mobile Layout for Homepage Carousel Slides 2 and 3

Please make a very targeted fix to the homepage hero carousel.

## Critical requirement

**DO NOT CHANGE THE DESKTOP OR LAPTOP VIEW.**

The existing desktop layout is already correct and must remain visually identical.

Only modify styles for screens below `768px`.

Use one of these approaches:

* Tailwind `max-md:` classes
* `@media (max-width: 767px)` CSS
* mobile-only wrapper classes

Do NOT replace existing desktop styles.

Do NOT change the existing `lg:` layout.

Do NOT modify the desktop mockup dimensions, desktop transforms, desktop spacing, or desktop typography.

---

## Safe implementation strategy

For every change you make, use this principle:

```tsx
Desktop/current style = unchanged
Mobile override = added separately
```

For example, do NOT change:

```tsx
width: "clamp(320px, 30vw, 420px)"
```

globally.

Instead, add a mobile class or CSS rule that overrides it only below `768px`.

Example concept:

```css
@media (max-width: 767px) {
  .hero-tablet-mobile {
    width: min(72vw, 340px);
    margin-inline: auto;
    transform: none;
  }
}
```

Desktop must continue using the original value.

# Slide 2 — Hire Without Limits

Current mobile problem:

The dashboard/tablet is still too tall.

It pushes the carousel controls completely below the visible hero.

The text and CTA now look good, so do not significantly alter them.

## Mobile-only fix

For `<768px` only:

### Tablet wrapper

Reduce the tablet visual to approximately:

```css
width: min(68vw, 330px);
max-width: 330px;
margin-inline: auto;
```

If necessary, use:

```css
transform: scale(0.82);
transform-origin: top center;
```

BUT ONLY on mobile.

Do not apply that scale to desktop.

### Remove 3D perspective on mobile

The current desktop tablet uses perspective / rotation.

Keep that on desktop.

On mobile only, use:

```css
transform: none;
```

or greatly reduce the rotation.

This will make the tablet visually centered and reduce accidental horizontal/vertical overflow.

### Visual wrapper

Place the tablet inside a mobile-only constrained visual area.

Example concept:

```css
@media (max-width: 767px) {
  .hero-device-area {
    width: 100%;
    max-height: 470px;
    overflow: hidden;
    display: flex;
    justify-content: center;
    align-items: flex-start;
  }
}
```

The bottom of the tablet may be intentionally cropped.

That is acceptable.

The important requirement is:

**the carousel navigation must remain visible.**

### Vertical spacing

Reduce the gap between:

* CTA button
* tablet

on mobile.

For example use around:

```css
margin-top: 18px;
```

instead of a large desktop gap.

Do not alter desktop spacing.
