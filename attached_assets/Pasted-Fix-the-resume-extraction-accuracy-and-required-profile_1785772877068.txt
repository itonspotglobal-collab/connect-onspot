Fix the resume extraction accuracy and required profile fields in FindBestMatches.tsx.

There are 2 main problems:

1. Resume parsing is still inaccurate.
2. Important personal information fields are marked optional when they should be required.

==================================================
PROBLEM 1 — WRONG NAME EXTRACTION
==================================================

Current bug:

After uploading a resume, the Full Name field is sometimes populated with a school/university name.

Example of incorrect result:
"Cebu Institute Of Technology University"

This is NOT a person's name.
It is an education institution.

The resume parser must not treat:
- school names
- universities
- companies
- section headings
- job titles
as candidate names.

Fix the name extraction logic.

==================================================
NAME EXTRACTION REQUIREMENTS
==================================================

When extracting Full Name from a resume:

1. Prioritize the resume header / contact section
2. Look near:
   - email
   - phone number
   - address/location
3. Prefer a likely human full name with:
   - 2 to 5 words
   - proper/title capitalization
   - optional middle initials
4. Reject organization/institution keywords

Reject candidate name values containing terms like:
- University
- College
- Institute
- School
- Academy
- Corporation
- Corp
- Inc
- Ltd
- Company
- Technologies
- Solutions
- Department
- Education

Also reject section headings such as:
- Education
- Tertiary Education
- Work Experience
- Experience
- Skills
- About Me
- Summary
- Career Objective
- References
- Projects

Example:

WRONG:
Cebu Institute Of Technology University

RIGHT:
A real person's full name from the resume header.

==================================================
USE CONFIDENCE-BASED EXTRACTION
==================================================

Create a stronger extraction strategy instead of taking the first matching line.

Example concept:

scorePotentialName(line):

+ strong score if:
- close to top of resume
- near email or phone
- 2–5 words
- mostly alphabetic
- title case

negative score if:
- contains University
- contains College
- contains Institute
- contains Inc
- contains Department
- matches section heading
- looks like company/job title

Only populate Full Name if confidence is high enough.

If no confident name is found:

leave Full Name blank.

DO NOT GUESS.

==================================================
EMAIL EXTRACTION
==================================================

Extract email using a reliable email regex.

If a valid email exists in the uploaded resume:
- prefill the Email field

Do not use placeholder values such as:
you@email.com

If extraction fails:
- leave the field blank
- require the user to enter it manually

==================================================
PHONE EXTRACTION
==================================================

Extract the candidate phone number if present.

Support formats such as:
- +63...
- 09...
- spaces
- hyphens
- parentheses

Normalize only if safe.

If the phone cannot be confidently extracted:
leave it blank.

==================================================
LOCATION EXTRACTION
==================================================

Try to extract candidate location/address from the contact/header section.

Prioritize:
- city
- province/state
- country
- address near phone/email

Do not infer a location from a school/company unless it is clearly identified as the candidate's location.

If uncertain:
leave it blank.
