# Remove Resume Section from Talent Profile

You are working inside the existing **OnSpot Global / connect-onspot** codebase.

Make one final focused change to the Talent Profile:

Remove the entire **Resume** section/card from the Talent Profile UI.

This applies to both:

* Talent owner view
* Client/visitor/public view of the Talent Profile

Primary file:

`client/src/pages/TalentProfile.tsx`

Do not redesign any other part of the profile.

---

# Remove Resume Section

The Talent Profile currently contains a card similar to:

```text
Resume

legaspi_resume.pdf
Uploaded
```

Remove this entire section from the Talent Profile page.

It must no longer render for:

* Talent owner
* Client viewing a Talent
* Public View
* logged-out visitor
* other Talent accounts viewing the profile

There should be no Resume card anywhere in the Talent Profile body.

---

# Remove Resume From Sticky Section Navigation

The Talent Profile also has a sticky section navigation/tab list.

Remove:

```text
Resume
```

from that navigation.

If the current section uses:

```text
section-resume
```

remove it from:

* `SECTION_TABS`
* `visibleSectionIds`
* any public-view visibility logic
* any scroll/IntersectionObserver setup that depends on that section

Do not leave a Resume tab that points to a missing section.

# Important: Do Not Delete Resume Functionality Globally

This task is ONLY about removing Resume from the Talent Profile display.

Do NOT remove or break:

* resume upload during Talent profile setup
* stored `resumeUrl`
* resume file storage
* job application resume upload
* Admin resume access
* Admin Job Applications resume view/download
* candidate resume APIs
* profile-completion logic that may still require a resume
* existing database fields related to resume

Resume should still exist internally and elsewhere in the platform.

It simply should not be displayed as a public/profile section.
