IMPORTANT:
This is NOT a change for only `FindWorkAllJobs.tsx`.

Inspect all connected pages/components that display when a job was posted and make sure they all use the same shared formatting logic.

Examples may include:
- `client/src/pages/FindWorkAllJobs.tsx`

- Find Work job cards
- Job Details / View Details

- any other component displaying "Posted X ago"

GOAL

Currently older job postings display dates like:

"Posted 3 months ago"
"Posted 5 months ago"
"3 Months Ago"

We no longer want to use MONTHS for job-posting age.

Months make the job posting visually feel much older.

Instead, once the age passes the day range, continue expressing the posting age in WEEKS.

Examples:

Current:
"Posted 3 months ago"

New:
"Posted 13 weeks ago"

Current:
"Posted 5 months ago"

New:
"Posted 22 weeks ago"

Do NOT approximate months and multiply them by 4.

Always calculate the weeks directly from the actual job posting date.

CALCULATE WEEKS FROM THE ACTUAL DATE

Do NOT do this:

months * 4

That is inaccurate.

Calculate elapsed milliseconds/days first:

const diffMs = now.getTime() - postedDate.getTime();

const diffDays = Math.floor(
  diffMs / (1000 * 60 * 60 * 24)
);

const diffWeeks = Math.floor(diffDays / 7);

Then format the result.

Use singular/plural correctly:

1 week ago
2 weeks ago

Never:

1 weeks ago
