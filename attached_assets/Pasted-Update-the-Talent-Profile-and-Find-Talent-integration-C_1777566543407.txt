Update the Talent Profile and Find Talent integration.

Current issue:

* The Talent Profile Page now allows profile photo changes.
* However, the updated profile photo and talent name are not showing on the Find Talent page.
* The Find Talent page is still showing fallback initials/candidate code instead of the updated name and uploaded photo.
* Also, the talent should be able to update their name from their own Profile Page.

Main requirements:

1. Allow the profile owner to edit their name.
2. Connect Talent Profile changes to the Find Talent page.
3. Make sure the Find Talent talent cards display the latest saved profile name and profile photo from the database.

Authentication rule:

* Only the profile owner can edit the profile.
* Continue using the existing authentication system only for the Talent Profile edit flow.
* Do not enable authentication globally yet.
* Other pages should remain accessible during development.

Requirements:

   * first name
   * last name
   * or full name/display name, depending on the existing data model.
3. If the project currently uses candidate code as fallback, keep that only as fallback.
4. Once the name is saved, update the database.

Suggested fields:

```ts
firstName?: string;
lastName?: string;
fullName?: string;
displayName?: string;
profilePhotoUrl?: string;
```

Recommended display priority:

```ts
const talentDisplayName =
```

Feature 2: Show Updated Name and Photo in Find Talent Page

Update the Find Talent page so it displays the saved profile name and profile photo from the database.

Requirements:

1. Update the employee/talent list API response to include:

   * profile photo URL
   * full name or display name
   * first name
   * last name
   * candidate code fallback
2. Update the frontend talent card mapping so it uses the same display name logic as the Talent Profile Page.
3. Update the talent card avatar logic:

   * If `profilePhotoUrl` exists, show the uploaded photo.
   * If no photo exists, show initials from the talent’s name.
   * If no name exists, show initials from candidate code.
4. Remove any hardcoded fallback that always shows `Candidate DB1DE6` when a real name exists.
5. Ensure the card updates after returning from the Talent Profile Page.
6. If data is cached, invalidate/refetch the talent list after profile updates.
7. Make sure the Quick View modal also shows the latest name and profile photo.

Suggested display logic:

```ts
const getTalentDisplayName = (talent) => {
  const fullName =
    talent.fullName ||
    talent.displayName ||
    [talent.firstName, talent.lastName].filter(Boolean).join(" ");

  return fullName?.trim() || `Candidate ${talent.candidateCode}`;
};

const getTalentInitials = (talent) => {
  const name = getTalentDisplayName(talent);

  if (name.startsWith("Candidate")) {
    return talent.candidateCode?.slice(0, 2)?.toUpperCase() || "TA";
  }

  return name
    .split(" ")
    .filter(Boolean)
    .map((part) => part[0])
    .join("")
    .slice(0, 2)
    .toUpperCase();
};
```

Suggested avatar logic:

```tsx
{talent.profilePhotoUrl ? (
  <img
    src={talent.profilePhotoUrl}
    alt={getTalentDisplayName(talent)}
    className="talent-avatar-image"
  />
) : (
  <div className="talent-avatar-fallback">
    {getTalentInitials(talent)}
  </div>
)}
```
