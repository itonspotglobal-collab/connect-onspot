# Replit Prompt — Talent Privacy + Job Opening Label Update

## 1. Protect Talent Names on Public Talent Cards

Update the public Talent Pool cards in:

`client/src/pages/TalentPool.tsx`

Talent cards must NOT display the talent's full legal/full name.

### Required format

Only the first name should be written in full.

Every remaining name should be reduced to its first initial.

Examples:

```text
Frenzy Val Eloise Legaspi
→ Frenzy V E L
```

```text
Maria Eubhe Regine T.
→ Maria E R T
```

```text
Ijeoma O.
→ Ijeoma O
```

```text
John Smith
→ John S
```

### Implementation

Create a reusable helper instead of implementing the formatting inline in JSX.

For example:

```ts
function formatPublicTalentName(name: string): string {
  const parts = name.trim().split(/\s+/).filter(Boolean);

  if (parts.length <= 1) {
    return parts[0] ?? "";
  }

  const [firstName, ...remainingNames] = parts;

  const initials = remainingNames
    .map((part) => part.replace(/\./g, "").charAt(0).toUpperCase())
    .filter(Boolean);

  return [firstName, ...initials].join(" ");
}
```

You may improve this implementation if necessary.

### Important privacy rule

Apply this specifically to PUBLIC candidate/talent displays.

Do NOT overwrite or modify the candidate's stored:

```ts
fullName
displayName
```

This is presentation-layer privacy only.

The backend/database should continue storing the real name.

### Public Talent Pool card

Where the card currently renders something similar to:

```tsx
candidate.displayName
```

or:

```tsx
candidate.fullName
```

change the displayed value to the privacy-safe version.

Prefer the same existing display-name priority, but mask the selected name afterward:

```ts
const rawDisplayName =
  candidate.displayName?.trim() ||
  candidate.fullName?.trim() ||
  "";

const publicDisplayName = formatPublicTalentName(rawDisplayName);
```

Then render:

```tsx
{publicDisplayName}
```

### Avatar initials

Check the Talent Pool card avatar fallback as well.

Do not expose additional name information through avatar initials.

Using something like:

```text
FV
```

for `Frenzy Val Eloise Legaspi` is acceptable.

Do not render the full name as hidden text, title text, tooltip, aria-label, or similar public UI unless it is necessary for accessibility and properly privacy-safe.

## 6. Privacy Edge Cases

The public-name formatter should handle:

```text
"Frenzy"
→ "Frenzy"
```

```text
"Frenzy Val"
→ "Frenzy V"
```

```text
"Frenzy Val Eloise"
→ "Frenzy V E"
```

```text
"Frenzy Val Eloise Legaspi"
→ "Frenzy V E L"
```

```text
"  Frenzy   Val Eloise   Legaspi  "
→ "Frenzy V E L"
```

Existing periods should not result in output such as:

```text
Frenzy V. E. L.
```

unless the site's design explicitly prefers periods.

For consistency with the requested format, use:

```text
Frenzy V E L
```
