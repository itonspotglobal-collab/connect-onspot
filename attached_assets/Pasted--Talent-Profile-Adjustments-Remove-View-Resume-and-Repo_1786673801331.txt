The Talent Profile currently displays a header action similar to:

```text

```

when the candidate has a resume.

Remove this action completely from the Talent Profile header.

The current implementation appears similar to:

```tsx

  <Button
    variant="outline"
    className="rounded-full text-sm"
    onClick={() =>
      window.open(`/api/candidates/${id}/resume-download`, "_blank")
    }
  >
    <FileText className="mr-1.5 h-4 w-4" />
    View Resume
  </Button>
)}
```

Remove this button from the header.

## Important visibility requirement

It must be removed from ALL Talent Profile viewing modes:

* Talent owner view
* Public View
* Client viewing a Talent
* visitor/logged-out view
* Admin viewing the same public profile, unless Admin has a separate dedicated internal resume action elsewhere

Do not just hide it for Talent accounts.

The profile header should no longer show a direct **View Resume** button at all.
