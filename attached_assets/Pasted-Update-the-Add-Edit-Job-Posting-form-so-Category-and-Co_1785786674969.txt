Update the Add/Edit Job Posting form so `Category` and `Contract Type` are free-text input fields instead of dropdowns.

Repository:
`itonspotglobal-collab/connect-onspot`

Primary file:
`client/src/components/JobFormModal.tsx`

Goal:
Admins and clients should be able to type any Category and Contract Type value they want when creating or editing a job posting.

Current behavior:
- `Category` is a dropdown with fixed options
- `Contract Type` is a dropdown with fixed options

New behavior:
- `Category` becomes a normal text input
- `Contract Type` becomes a normal text input
- custom values must be saved to the database
- existing jobs must continue loading and editing correctly

1. Replace the Category dropdown

Find the current Category `Select` block in `JobFormModal.tsx`.

Replace it with an `Input`.

Expected structure:

```tsx
<div className="space-y-2">
  <Label htmlFor="modal-category">
    Category <span className="text-red-500">*</span>
  </Label>

  <Input
    id="modal-category"
    type="text"
    value={formData.category}
    onChange={(e) => updateField("category", e.target.value)}
    placeholder="e.g. Admin & Support, Healthcare, Accounting"
  />

  {errors.category && (
    <p className="text-xs text-red-500">{errors.category}</p>
  )}
</div>

Remove the fixed category options such as:

support
development
design
marketing
writing
media

Do not convert the typed value to a slug automatically when saving.

    .trim()
    .toLowerCase()
    .replace(/&/g, "and")
    .replace(/[^a-z0-9]+/g, " ")
    .trim();
}
