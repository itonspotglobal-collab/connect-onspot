You are working inside the existing **OnSpot Global / connect-onspot** codebase.

# Primary Goal

The Talent Profile should feel like a polished professional profile rather than a collection of equally weighted cards.

There should be a clear visual hierarchy:

```text
Profile identity
↓
Professional introduction
↓
Detailed background
↓
Qualifications and proof
↓
Career/application information
↓
Preferences / supporting information
```

The user should immediately understand:

1. Who this Talent is
2. What they do
3. What they are good at
4. Their professional background
5. Additional information about them

# 1. About and More About Me — Justified Text

Update the display styling of:

```text
About
More About Me
```

so long-form text uses **justified alignment**.

Use:

```css
text-align: justify;
```

or Tailwind:

```text
text-justify
```

if available in the project.

If Tailwind does not include the desired utility, use:

```tsx
style={{ textAlign: "justify" }}
```

or a reusable CSS class.

# Long-Form Typography

Both About and More About Me should use comfortable long-form reading styles.

Recommended:

```text
text-[15px] or text-base
leading-7
text-slate-700
dark:text-slate-300
```

Avoid:

* tiny body text
* compressed line-height
* very wide text lines
* giant blocks without paragraph spacing

---

# Paragraph Formatting

Continue preserving paragraph breaks.

Example input:

```text
To succeed and be a part of a competitive organization that provides possibilities for professional development.

I am particularly interested in environments where I can contribute while continuously learning and improving.

My long-term goal is to...
```

should visually render as:

```text
Paragraph 1

Paragraph 2

Paragraph 3
```

Each paragraph should be justified independently.

Recommended structure:

```tsx
<div className="space-y-4">
  {paragraphs.map((paragraph, index) => (
    <p
      key={index}
      className="text-[15px] leading-7 text-slate-700 dark:text-slate-300"
      style={{ textAlign: "justify" }}
    >
      {paragraph}
    </p>
  ))}
</div>
```

Do not use `dangerouslySetInnerHTML`.

# Important Justification Detail

Avoid ugly giant spaces between words.

Use CSS that produces reasonable justification.


Do not force justification on:

* headings
* skill badges
* metadata
* labels
* dates
* job titles

Only use justification for long prose content.

# 21. Long Text Styling Helper

To avoid duplicating About and More About Me paragraph rendering, create a small reusable component if appropriate.

Example:

```tsx
function ProfileLongFormText({
  value,
}: {
  value: string;
}) {
  const paragraphs = value
    .split(/\n\s*\n/)
    .map((p) => p.trim())
    .filter(Boolean);

  return (
    <div className="max-w-prose space-y-4">
      {paragraphs.map((paragraph, index) => (
        <p
          key={index}
          className="text-[15px] leading-7 text-slate-700 dark:text-slate-300"
          style={{
            textAlign: "justify",
            textJustify: "inter-word",
          }}
        >
          {paragraph}
        </p>
      ))}
    </div>
  );
}
```

Use it for:

```text
About
More About Me
```

Do not use it for short metadata fields.
