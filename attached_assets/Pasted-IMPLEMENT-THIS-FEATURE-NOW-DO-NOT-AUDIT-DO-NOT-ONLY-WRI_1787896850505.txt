NEW PRODUCT POLICY
============================================================

PIPELINE
============================================================

For every new user-generated chat message:

1. Validate authentication.
2. Validate thread membership.
3. Validate message content.
4. Run deterministic privacy detection.
5. Redact detected sensitive content.
6. Optionally run Vanessa semantic privacy detection.
7. Apply any additional Vanessa-approved redactions.
8. Store ONLY the sanitized message content.
9. Set flagged_for_review when appropriate.
10. Update thread last_message_at.
11. Create notifications.
12. Return sanitized content only.

The recipient must never receive the raw unfiltered content.

============================================================
EMAIL REDACTION
============================================================

Detect normal email formats, including:

val@onspotglobal.com
hello@gmail.com
john.doe+jobs@example.co.uk

Desired masking:

val@onspotglobal.com
→ *****.com

john@gmail.com
→ *****.com

name@example.co.uk
→ *****.co.uk

In general:
- hide the username
- hide the domain name
- preserve only the public suffix/TLD portion when practical

DO NOT expose:

val@*****
v***@onspotglobal.com
*****@onspotglobal.com

because those still reveal useful contact information.

Preferred:

*****.com

or for multi-part public suffix:

*****.co.uk

============================================================
OBFUSCATED EMAIL DETECTION
============================================================

Detect common attempts such as:

val at gmail dot com
val [at] gmail [dot] com
val(at)gmail(dot)com
val @ gmail . com
v a l @ gmail . com

When detected, redact the entire contact-bearing expression.

Example:

"email me at val at gmail dot com"

becomes:

"email me at *****.com"

Do not over-mask ordinary sentences containing words like "at" and "dot" unless the surrounding pattern strongly resembles an email.

============================================================
PHONE NUMBER REDACTION
============================================================

Detect common phone formats:

09171234723
9171234723
+639171234723
+63 917 123 4723
(0917) 123-4723
0917-123-4723

Redaction rule:

Preserve at most the LAST FOUR digits.

Examples:

+63 917 123 4723
→ ***4723

09171234723
→ ***4723

(0917) 123-4723
→ ***4723

If fewer than four safe trailing digits exist, redact the entire number.
