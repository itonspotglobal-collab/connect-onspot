Reorganize the Admin Add/Edit Job Posting form so its FIELD SEQUENCE matches the public "View Job Details" page structure.

IMPORTANT:
- Do NOT fully redesign the form.
- Keep the current modal, controls, styling, validation, buttons, and existing functionality.
- This task is mainly about SECTION ORDER and logical grouping.
- The goal is to make the Admin form easier to understand because admins should enter information in roughly the same order candidates will see it on the public Job Details page.

Primary areas to inspect:
- Add New Job Posting modal/form
- Edit Job Posting modal/form
- any reusable JobForm component
- admin preview
- shared form schema/types
