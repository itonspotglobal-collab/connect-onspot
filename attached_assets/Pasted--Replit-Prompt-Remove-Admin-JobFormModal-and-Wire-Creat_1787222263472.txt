# Replit Prompt — Remove Admin JobFormModal and Wire Create/Edit to Dedicated Job Pages

The Admin Job Posting redesign has already been implemented as dedicated full-page Create/Edit pages, but the `/admin/find-work` dashboard is still opening the legacy `JobFormModal` popup.

This task is to remove the modal-based Create/Edit flow from the Admin dashboard and wire all Admin job actions to the new page routes.

## Existing dedicated Admin routes

These already exist and should be used:

```text
/admin/find-work/jobs/new
/admin/find-work/jobs/:jobId/edit
```

The new full-page form is already implemented in:

```text
client/src/pages/JobFormPage.tsx
```

Do NOT rebuild or redesign the job form.

The issue is specifically that `/admin/find-work` is still opening:

```text
JobFormModal.tsx
```

instead of navigating to the new routes.
