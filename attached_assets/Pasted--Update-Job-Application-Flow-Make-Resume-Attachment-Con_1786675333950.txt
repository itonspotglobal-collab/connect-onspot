# Update Job Application Flow — Make Resume Attachment Configurable Per Job

You are working inside the existing **OnSpot Global / connect-onspot** codebase.

Implement a job-level setting that allows Admin to decide whether applicants are required to attach a Resume/CV.

The current application form always includes CV / Resume in Step 2 and currently treats it as required.

Change this behavior so Resume is controlled by the individual job posting.

There are two main requirements:

1. For now, new jobs should **NOT require a resume by default**.
2. In Admin Create/Edit Job, provide a toggle allowing Admin to enable or disable Resume attachment for each role.

Do not remove resume infrastructure globally.

# Dynamic Application Steps

# FEATURE 5 — Update Resume Validation

Current application validation appears to require:

```ts

```

Change it so Resume validation is conditional.

Conceptually:

```ts
if (requiresResume && !resolvedResume) {
```

Successful validation should be:

```ts
const resumeValid =
  !requiresResume || hasResume;

  !requiresVideoIntro || !!videoFile;

return fieldsValid && resumeValid && videoValid;
```

Use the actual current application implementation.

# Final Implementation Rule

The desired model is:

```text
Job Configuration
      ↓
requiresResume
requiresVideoIntro
      ↓
Application Form
      ↓
Show only required documents
      ↓
Backend validates the same rules
```

Do not make Resume globally required anymore.

Do not make Resume globally unavailable either.

Resume must now be a **per-job application requirement controlled by Admin**.
