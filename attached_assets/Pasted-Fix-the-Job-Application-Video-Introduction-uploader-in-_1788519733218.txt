## Current expected frontend behavior

JobApplyPage.tsx already supports:

* jobs where `requiresVideoIntro === true`
* selecting/uploading a new video
* reusing an existing Talent Profile video
* MP4
* MOV / QuickTime
* WebM
* maximum file size of 200 MB

```ts

```

For an existing profile video, it sends:

```ts
formData.append("useProfileVideo", "true");
```

The request goes to:

```text
POST /api/jobs/:jobId/apply
```

using multipart/form-data.

The current client validation is already approximately:

```ts
const allowedTypes = [
  "video/mp4",
  "video/quicktime",
  "video/webm"
];
```

and max size:

```text
200 MB
```
