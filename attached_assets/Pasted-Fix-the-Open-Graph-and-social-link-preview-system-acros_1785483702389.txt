`OnSpot – The Superhuman Outsourcing System`

This must be fixed for every public route, not only the homepage.

Primary goal:
Every public OnSpot URL must return correct server-rendered social metadata in the initial HTML response, including a valid preview image that social crawlers can access without JavaScript.

New default branding:

Title:
`OnSpot – Work Without Limits`

Default social image:

────────────────────────────

Social crawlers may not execute JavaScript.

Every route must include its correct metadata directly in the initial HTML returned by the server.

The raw HTML must contain one effective instance of:

```html
<title>...</title>
<meta name="description" content="...">

<link rel="canonical" href="...">

<meta property="og:title" content="...">
<meta property="og:description" content="...">
<meta property="og:type" content="website">
<meta property="og:url" content="...">
<meta property="og:image" content="https://onspotglobal.com/onspot-social-preview-v3.png">
<meta property="og:image:secure_url" content="https://onspotglobal.com/onspot-social-preview-v3.png">
<meta property="og:image:type" content="image/png">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
<meta property="og:image:alt" content="OnSpot – Work Without Limits">

<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:title" content="...">
<meta name="twitter:description" content="...">
<meta name="twitter:image" content="https://onspotglobal.com/onspot-social-preview-v3.png">

Do not rely only on:

React Helmet
useEffect
Client-side DOM updates
document.title
HeadSEO.tsx
JavaScript route changes

Client-side metadata may remain for navigation consistency, but the initial server response is the source of truth for crawlers.

6. Fix middleware order
────────────────────────────

Ensure metadata injection happens before static files and SPA fallback.

The server order should be equivalent to:

app.use(ogMiddleware);
app.use(express.static(clientDistPath));
app.get("*", serveSpaWithInjectedMetadata);

If express.static() serves index.html before the metadata middleware can modify it, fix that.

Do not allow the SPA fallback to bypass metadata generation.

If needed:

Disable automatic index serving in express.static
Read the production HTML template
Inject escaped metadata
Return the modified HTML per request

Example:

app.use(
  express.static(clientDistPath, {
    index: false,
  }),
);

Then serve the HTML through one controlled catch-all route.
