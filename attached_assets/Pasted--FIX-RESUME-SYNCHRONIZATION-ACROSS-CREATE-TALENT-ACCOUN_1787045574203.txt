# FIX RESUME SYNCHRONIZATION ACROSS CREATE TALENT ACCOUNT, TALENT PROFILE, AND PROFILE SETTINGS

You are working inside the existing **OnSpot / connect-onspot** project.

There is currently a synchronization bug with talent resumes.

The following three areas belong to the **same Talent/Candidate account** and MUST use the exact same resume record:

1. **Create Talent Account / Talent Signup**
2. **Talent Profile Page**
3. **Talent Profile Settings Page**

Right now, uploading a resume from one page does not reliably appear on the other pages.

Fix this permanently.

---

# Core Requirement

There must be **ONE canonical resume per candidate**.

All three pages must:

* read the same resume
* upload/replace the same resume
* delete the same resume
* display the same resume filename
* display the same current resume state
* refresh automatically after a change

Do NOT create three different resume records.

Do NOT maintain separate resume URLs for signup, Talent Profile, and Profile Settings.

The database-backed **Candidate resume fields must be the single source of truth**.

---
