==================================================
GLOBAL ACCENT COLOR
==================================================

Create or reuse a single accent color variable/class if possible.

Preferred CSS variable:

:root {
  --onspot-brand: #3F4698;
  --onspot-brand-soft: rgba(63, 70, 152, 0.10);
  --onspot-brand-border: rgba(63, 70, 152, 0.22);
}

Then use it for highlights/accent text.

If using Tailwind directly, replace bright purple classes with:

text-[#3F4698]
border-[#3F4698]
bg-[#3F4698]
bg-[#3F4698]/10
border-[#3F4698]/25
