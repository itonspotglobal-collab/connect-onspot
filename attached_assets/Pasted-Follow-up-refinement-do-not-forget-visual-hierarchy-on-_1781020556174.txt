Follow-up refinement: do not forget visual hierarchy on the updated homepage sections.

The latest section changes are good, but please make sure the typography and layout follow a clear visual hierarchy, especially using an inverted pyramid / cascading hierarchy.

Apply this to these sections:
1. Insights
2. Work Differently
3. Real people. Real work. Real impact.
4. Why OnSpot
5. The People Behind the Platform

General hierarchy rules:
- Eyebrow/section label should be the smallest.
- Main title should be the strongest, but not oversized.
- Highlighted gradient words should draw attention without overpowering the full heading.
- Supporting paragraph should be smaller and narrower than the title.
- Cards/tables should sit below with enough spacing, but still fit comfortably in one screen where possible.
- CTA buttons should be visually noticeable but not compete with the main headline.
