Please update the OnSpot Login and Sign Up navigation/UI to support dedicated Client and Talent URLs.

IMPORTANT SCOPE / SAFETY RULES

This is primarily a ROUTING + NAVIGATION + UI improvement.

DO NOT audit or refactor unrelated parts of the project.
DO NOT redesign the backend authentication architecture.
DO NOT create another authentication system.
DO NOT duplicate the existing Client or Talent login/signup logic.
DO NOT replace working API endpoints.
DO NOT change database schemas.
DO NOT break the existing AuthContext, Talent auth/session handling, password setup, forgot-password behavior, redirects, or profile creation logic.
DO NOT modify unrelated frontend or backend functionality.

Reuse the CURRENT WORKING login and signup functions/components/services.

Before making changes, inspect only the files directly involved in:
- authentication UI
- login/signup routing
- existing Client/Talent authentication handlers
- homepage navigation buttons

Do not perform a broad project audit.

==================================================
GOAL
==================================================

We want separate, shareable authentication URLs for Client and Talent users so that invite links clearly identify which portal the person is accessing.

Desired URLs:

LOGIN
/login
/login/client
/login/talent

SIGNUP
/signup
/signup/client
/signup/talent

These are NOT separate authentication systems.

They are separate UI/routes around the SAME existing authentication functionality.

==================================================
1. /login SHOULD BECOME A PORTAL CHOOSER
==================================================

When a logged-out user clicks the homepage "Log In" button:

Redirect them to:

/login

The /login page should NOT initially show email/password fields.

Instead show a clean OnSpot role-selection page.

Example:

OnSpot
WORK WITHOUT LIMITS

Welcome back
Choose how you want to access OnSpot.

[ Client ]
Hire and manage outsourcing talent.

[ Talent ]
Find jobs and manage your career profile.

Back to Home

Selecting Client:
→ /login/client

Selecting Talent:
→ /login/talent

Do not ask users to select Client/Talent again after reaching the role-specific page.
