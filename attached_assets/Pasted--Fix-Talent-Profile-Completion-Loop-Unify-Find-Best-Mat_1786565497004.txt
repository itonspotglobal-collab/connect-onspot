# Fix Talent Profile Completion Loop — Unify Find Best Matches + Profile Settings

There is now a major inconsistency in the Talent onboarding/profile-completion flow.

## Current problem

A Talent can complete the **Find Best Matches** journey multiple times, but when navigating to Talent Profile the system still redirects them back to Find Best Matches.

At the same time:

* Profile Settings has its own completion data;
* Talent Profile has another completion percentage/state;
* the Talent dropdown may show another completion value;
* Find Best Matches has its own 5-step completion journey.

These systems are no longer synchronized.

The result is an onboarding loop:

```text
Complete Find Best Matches
→ go to Talent Profile
→ system still thinks profile is incomplete
→ redirects back to Find Best Matches
→ repeat
```

This must be fixed permanently.

---

# Goal

Create ONE canonical Talent profile-completion system.

Both:

```text
Find Best Matches
```

and:

```text
Profile Settings
```

must update the SAME Candidate profile data.

Then:

```text
Talent Profile
Top Navigation dropdown
Profile Settings
Find Best Matches
```

must all read completion from the SAME persisted Candidate data and shared completion calculator.

The database must be the source of truth.

---

# Core architecture

The desired architecture is:

```text
Find Best Matches
        ↓
   Candidate DB
        ↑
Profile Settings
        ↓
Shared Profile Completion Calculator
        ↓
Talent Profile
Top Navigation
Settings
Find Best Matches
```

NOT:

```text
Find Best Matches local completion
+
Profile Settings completion
+
Talent Profile completion
+
Navbar completion
```

with separate values.

# 8. Separate profile completion from Find Best Matches journey progress

This is important.

These are two different concepts:

### Journey progress

```text
Step 1 of 5
20% complete
```

This means the user is on step 1 of Find Best Matches.

### Profile completion

```text
58% profile complete
```

This means the Candidate's persisted profile contains 58% of required profile data.

Do not mix them.

Find Best Matches may show:

```text
Journey: Step 5 of 5
Profile: 83% complete
```

if required profile fields are still missing.

But completing the journey should persist enough data that the Candidate profile reflects the work that was completed.

Talent Profile access should not depend on:

```text

```

or:

```text

```

Instead, determine whether the Talent has enough persisted profile data to access the profile.

Prefer allowing Talent Profile access even when incomplete.

Do NOT continuously redirect incomplete users away from Talent Profile.

Instead show the existing CTA:

```text

```

with:

```text
Finish Setting Up
```

This is a much better UX than a redirect loop.
