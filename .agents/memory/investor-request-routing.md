---
name: Investor request routing
description: Owner-approved routing and delivery expectations for the three investor actions.
---

All three Investors calls to action use one persisted intake, record which action the visitor chose, and notify the existing publicly listed founder contact. A pitch-deck request is a request for follow-up, not a claim that a deck has already been sent.

**Why:** The owner explicitly chose one intake and founder notification for every action. The previous meeting link led to a broader lead form, while the deck link did not deliver a deck.

**How to apply:** Persist before attempting delivery. Confirm when notification is accepted, but if sending fails, tell the visitor their request was saved and the notification was not sent; do not imply that a founder saw an undelivered email.
